# Museum_landing

[Visit the Website](https://lishvets.github.io/Museum_landing) | [View Figma Design](https://www.figma.com/design/cRBCqE06cDrY3s4jX7h3iY/%25D0%259D%25D0%2590%25D0%259C%25D0%25A3--Edit-?node-id=320-108&t=SQdR0uOqG7wxILbH-0)

A modern, responsive landing page for the National Art Museum of Ukraine (NAMU). The project is designed to introduce visitors to current exhibitions, lectures, working hours, and newsletter subscriptions.

## Project Overview

- **Tech Stack:** HTML5, SCSS, JavaScript, Swiper.js
- **Architecture:** BEM (Block Element Modifier) methodology
- **Performance & Standards:**
  - Semantic and fully validated HTML5 structure
  - Optimized image assets and vector SVG icons for modern high-DPI screens
  - Cross-browser support with clean CSS resets
  - Mobile-First layout approach

## Development Details

- **Mobile-First Workflow:** Designed starting with mobile viewports and scaling smoothly to tablet and desktop sizes.
- **SCSS Architecture:** Modular file structure utilizing SCSS variables, mixins, and nested rules for maintainable styling.
- **Responsive Layouts:** Built using CSS Grid and Flexbox for fluid positioning of events, photo galleries, and footer information.
- **Touch-Friendly Controls:** Integrated interactive mobile menu drawer and Swiper slider for smooth touch-based touch navigation.

## Features
- **Interactive Header & Navigation:** Quick-access navigation with fixed header elements and smooth scrolling to sections.
- **Mobile Menu Drawer & Working Schedule:** Full-screen mobile menu containing interactive links and detailed working hours.
- **Exhibitions & Events Section:** Clean card layout showcasing current museum exhibitions, dates, and special lecture banners.
- **Responsive Swiper Gallery:** Touch-enabled photo slider for mobile viewports, smoothly transitioning into a multi-column image grid on larger screens.
- **Newsletter Subscription:** Interactive form with instant feedback for email subscriptions.
- **Full Contact Footer:** Comprehensive footer featuring interactive location map links, phone numbers, email, and smooth scroll-to-top controls.
